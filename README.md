# دفتر التداول (Trading Journal)

تطبيق شخصي لتسجيل صفقات الفوركس والذهب، مبني من ملف Excel الأصلي.

## التشغيل
```
npm install
npm run dev        # تطوير
npm test           # اختبارات المحرك (Node 22.6+)
npm run build      # فحص الأنواع + بناء dist/
npm run preview    # تجربة النسخة المبنية (PWA تعمل في الإنتاج فقط)
```
## النشر
انسخ مجلد `dist/` إلى أي استضافة ثابتة تعمل بـ HTTPS (Netlify/GitHub Pages/Cloudflare Pages). افتح الرابط ثم «تثبيت التطبيق» من المتصفح.

## البيانات
مخزّنة محليًا في IndexedDB داخل متصفح الجهاز فقط ولا تُرفع لأي مكان. مسح بيانات الموقع يحذفها: استخدم **النسخ الاحتياطي ← نسخة JSON كاملة** بانتظام، والاستعادة من الصفحة نفسها (دمج بلا حذف أو استبدال).

## البنية
`src/engine` الحسابات والمخاطر والتحليلات (بلا واجهة) · `src/db` التخزين · `src/import` استيراد Excel · `src/backup` النسخ · `src/images` الصور · `src/pages` الشاشات · `tests` الاختبارات والمطابقة.

## تقارير
`PHASE1_ANALYSIS.md` تحليل الملف · `RECONCILIATION.md` المطابقة · `FEATURES_REPORT.md` المنفّذ وغير المنفّذ.

## الرفع على GitHub والنشر
1. أنشئ مستودعًا جديدًا وارفع محتويات هذا المجلد (فكّ الـ zip أولًا) على الفرع `main`.
2. من Settings ← Pages ← Source اختر **GitHub Actions**.
3. أي push يشغّل الاختبارات ثم البناء ثم النشر، ويظهر الرابط في تبويب Actions. إن فشلت خطوة البناء فأرسل لي نص الخطأ.
